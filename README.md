# 성지몬

입체도형 형태의 `지냄`을 모으고 10구역 던전을 돌파하는 브라우저 턴제 로그라이트 게임이다.

## 게임 구조

- 로비 → 던전 → 턴제 배틀 → 보상 선택 → 다음 구역
- 전투 불능 또는 원정 포기 시 해당 원정 종료
- 던전에서 얻은 티켓은 종료 후에도 보존
- 티켓 전용 차원 뽑기와 30회 Smell 이상 확정 시스템
- Fragrance, Aroma, Scent, Odor, Smell, Xion의 6등급
- 브라우저 저장소를 이용한 도감·티켓·최고 기록 자동 저장
- 모바일과 데스크톱 대응

## 실행

별도 설치 없이 `dist/index.html`을 브라우저에서 열면 된다. 정적 웹서버에서는 `dist` 폴더를 루트로 지정한다.

## 안내

뽑기는 게임 플레이로 획득하는 무료 티켓만 사용한다. 유료 결제나 현금성 요소는 없다.
