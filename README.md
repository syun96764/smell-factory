# 성지몬

입체도형 형태의 `지냄`을 포획하고 장기 던전을 돌파하는 브라우저 턴제 로그라이트 게임이다.

## 게임 구조

- 로비 → 난이도별 던전 선택 → 턴제 배틀 → 보상 선택 → 다음 구역
- 전투 불능 또는 원정 포기 시 해당 원정 종료
- 전투 중 조우한 적 지냄을 한 번 포획 가능
- 적의 HP가 낮을수록 포획 성공률 상승, 등급이 높을수록 난도 상승
- 포획 성공 시 즉시 도감에 등록되며 최종보스 `성지온`은 포획 불가
- Fragrance, Aroma, Scent, Odor, Smell, Xion의 6등급
- 72종 지냄과 12종의 고유 특성
- EASY 12구역부터 NIGHTMARE 24구역까지 4개 던전
- XION 심층 마지막 구역의 전용 최종보스 `성지온`
- 상대 지냄의 회복·흡수·보호막 효율은 플레이어의 25%
- 기술별 회복, 보호막, 지속 피해, 능력 변화, 행동 봉쇄, 반동 등 서로 다른 효과
- 던전 진입 전 보유 지냄 중 출전 지냄 선택
- 냄새·벌레·악·마래·고스트의 5타입과 4배·2배·1배·1/2배·1/4배 상성 표시
- HP·공격·방어·특수공격·특수방어·스피드의 6종 종족값
- 물리·특수 기술 분리, 스피드 기반 행동 순서, 구역별 기술 PP와 전 기술 PP 소진 시 자동 복귀
- 난이도·진행 구역·운 수치에 따라 달라지는 4단계 보상 희귀도와 11종 보상
- 포획·클리어·전투·타입별 완전 수집·등급별 완전 수집을 추적하는 21종 업적
- 지냄별 도감 상세 페이지: 종족값, 타입, 상성, 특성, 기술, 설명
- 브라우저 저장소를 이용한 도감·포획·최고 기록 자동 저장
- 모바일과 데스크톱 대응

## 실행

별도 설치 없이 `dist/index.html`을 브라우저에서 열면 된다. 정적 웹서버에서는 `dist` 폴더를 루트로 지정한다.

## 안내

유료 결제나 확률형 상품은 없다. 모든 지냄은 던전 전투에서 직접 포획한다.
